## 1. Frozen scientific question (contract §2.1)

For a finite, pre-registered RNA observation system, given two target/rival model classes, a finite
implementable action library, and a fixed replication budget:

1. Does there exist a target/rival pair that collides under the passive marginal map AND still produces
   the identical observation law under the selected actions?
2. If not, can we return an independently checkable robust separation certificate?
3. How does that separation convert to a fixed-horizon, abstention-allowed finite-sample risk,
   correct-declaration probability, and budget bound?
4. With unequal action cost, can we output an integer panel, LP-dual burden lower bound, integrality gap,
   and design-class no-go certificate?

These are answered only within the registered finite model class. They are not equivalent to solving
general RNA structure inference nor to empirical validation of future wet-lab outcomes.

## 2. Frozen model objects (contract §2.2, §6.1)

- **Latent state space** `Omega`: finite set of RNA structural/eligibility states (size locked at T2-1).
- **Model classes** `Theta_0` (target), `Theta_1` (rival): finite catalogs or rational polyhedral classes
  over the probability simplex, with linear constraints.
- **Passive marginal map** `M`: linear projection of a state distribution; fixing `M` defines the
  collision fiber.
- **Cross-class difference set** `D = { x_1 - x_0 : x_i in Theta_i, M x_0 = M x_1 }`. The full set `D`
  must be used; a hand-listed cycle-generator subset is forbidden unless a completeness theorem holds
  (contract §3.1).
- **Action library** `U`: finite; each action `u` has finite observation alphabet `Y_u` and complete
  categorical law `q_u(theta_i, xi_i)`; RNA-feasibility rules registered.
- **Nuisance** `xi in Xi`: finite domain, registered coupling (`CARTESIAN` or `EQUAL_REALIZED_VALUE`),
  registered conditioning and action-level independence.
- **Design**: deterministic, non-adaptive, fixed-horizon allocation `n_u`; action cost `c_u`; budget `n`.
- **Endpoints**: `alpha` (wrong-decision), `beta`, `kappa_0`, `kappa_1` (correct-declaration), abstention rule.

## 3. Quantifier and dependency rules (contract §5.5)

- The order `sup_{d in D_design} inf_{xi in Xi} R(d,xi)` and `inf_{xi in Xi} sup_{d in D_design} R(d,xi)`
  are **not** interchangeable; every theorem must declare which.
- Cross-action sharing, shared batch effects, state-changing actions, dropout, dependent observations,
  and unobserved third state must be explicit scenarios; on assumption breach the theorem must
  abstain/refuse/withdraw applicability.

## 4. Theorem stack in scope (contract §5)

- **T2a** Scoped alternating-cycle lemma: only for 2D fixed-marginal tables or decomposable/chordal model;
  never headline novelty; cannot directly give finite-sample separation.
- **T2b** Exact collision-or-separation theorem: `gamma(S)=0` -> exact replayable collision witness;
  `gamma(S)>0` -> independently checkable separation certificate; support `IFF`/`NECESSARY_ONLY`/`SUFFICIENT_ONLY`.
- **T2c** Finite-sample quantitative theorem: primary endpoint is a non-asymptotic sample-complexity/budget
  result; lower/upper bounds bound by `alpha,beta,kappa_0,kappa_1`, uniformity domain, abstention rule, budget.
  Information form `I_uw = -log sum_y sqrt(p_0uw(y) p_1uw(y))`. `T2_TV_SEPARATION_BOUND_ACCEPTED` is only
  intermediate; `T2_SAMPLE_COMPLEXITY_BOUND_ACCEPTED` requires nontrivial, uniform, constant/certified-error result
  with exact-microcase crosscheck.
- **T2d** Costed design and no-go: integer panel, LP relaxation, primal/dual receipts, dual burden lower bound,
  integrality gap, independent checker; LP-feasible does not imply integer-feasible; dual bound above budget is
  the design-class no-go certificate.

## 5. Prior-art collision matrix (contract §4.1)

Each row is prior art that D2T-RNA must acknowledge; the columns state whether that prior art already
covers the potential T2 claim (COLLISION) or leaves a bounded delta for D2T-RNA.

| Ref | Prior art (must acknowledge) | T2 claim candidate | Collision? | Allowed delta |
|-----|-------------------------------|--------------------|------------|---------------|
| Diaconis & Sturmfels 1998 | Fixed-marginal fiber, 2x2 moves, Markov-basis framework | T2a alternating-cycle correspondence | COLLISION | Scoped 2D/decomposable restatement only; not headline novelty |
| Dobra 2003 | Markov bases for decomposable graphical models | T2a scope | COLLISION | Bounded by decomposable scope |
| De Loera & Onn 2005 | 3-way tables: Markov moves arbitrarily complicated | T2a boundary / T2-1 counterexample | COLLISION | Use as boundary/counterexample, not a claim |
| Bounded-table Markov bases (arXiv:0905.4841) | primitive swaps for bounded 2D tables | T2a moves | COLLISION | Scoped only |
| Test Cover (arXiv:1212.0117) | minimal action coverage degenerates to Test Cover | T2d minimal panel | COLLISION | Must not claim Test-Cover selection as novelty |
| Fixed-Horizon Active Hypothesis Testing (arXiv:1911.06912) | inconclusive declaration, correct/wrong prob joint bounds | T2c decision endpoints | COLLISION | Delta: composite finite-class catalog + coupling handling |
| Simple Binary Hypothesis Testing sample complexity (arXiv:2403.16981) | TV/Hellinger, Chernoff, Hoeffding, sample complexity | T2c information/bounds | COLLISION | Delta: uniform finite composite class + coupling |
| Bhargav et al. 2024 | information-source selection, costed design, approx submodularity | T2d costed panel | COLLISION | Delta: exact integer/LP-dual no-go on registered catalog |

**Novelty delta (contract §4.2)** — T2 novelty may only lie in the combination of:
1. explicit registration/construction of RNA-feasible composite uncertainty;
2. computable handling of target/rival cross-class coupling and shared nuisance;
3. restricted action-image separation over the **full** `D` (not a generator list);
4. returning an exact collision witness or robust separation certificate for a finite RNA action/observation catalog;
5. converting that geometry to a nontrivial, uniform, explicit-constant/certified-error finite-sample
   sample-complexity/budget consequence;
6. integer panel + LP-dual no-go certificate + independent checker receipt on the same registered object.

If independent review judges T2 to be only an RNA rewrite of kernel/rank, Markov basis, Test Cover,
TV/Hellinger, Hoeffding, Chernoff, or active-testing results, then `T2_NOVELTY_NOT_ESTABLISHED` must be
written and the strong RNA-methods claim stopped (contract §4.2).
