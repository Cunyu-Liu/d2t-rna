# D2T-RNA v7 — §12.3-6 Authority Amendment (2026-08-05)

**Contract:** D2T-RNA v7.0.0 (`ACTIVE_SUCCESSOR_FOR_FUTURE_TASKS`)
**Amendment ID:** `V7_AMEND_12_3_6_20260805`
**Status:** APPROVED_BY_USER (explicit direction, 2026-08-05)
**Scope:** §12.3 condition 6 (submission-ready gate) + §8.4/§8.5 R2 terminal-outcome classification.

## 1. Rationale

A read-only audit of the add/RMDB dataset (accession `ADDRSW_SHP_0003`) established that its
observed modality is **continuous per-nucleotide SHAPE reactivity** (Mutate-and-Map, Kladwang et
al. 2011; 72 single-variant constructs, one reactivity vector each, no replicate dimension). This
is structurally identical to the sam-iii DMS modality, which the accepted §8.5 modality-transfer
diagnostic already classifies as `NOT_COMPARABLE_BY_REGISTERED_ACTION_SPACE`.

Because add offers **no registered categorical observation channel over latent states**, a
categorical full-matrix replay of the T2 form is not constructible under the registered framework.
This is a modality limitation, not missing data. §12.2 already states that data eligibility failure
does not block the T2 pure-theory main manuscript and degrades the dataset to a descriptive /
fail-closed role. §1.2 likewise limits public RNA data to optional retrospective compression,
modality diagnostics, and model-misspecification cases.

The original §12.3 condition 6 ("at least one add full-matrix replay AND one RORC fail-closed case
fully reported") therefore over-specifies a structurally impossible requirement relative to the
achievable scientific scope. It is replaced below by an equivalent-but-achievable gate that keeps
the mandatory audit/report obligation intact.

## 2. Amendment (normative)

Condition 6 of §12.3 is replaced by:

```
QUALIFIED_RETROSPECTIVE_CASE  OR  COMPLETE_FAIL_CLOSED_ONLY_AUDIT
```

- `QUALIFIED_RETROSPECTIVE_CASE`: at least one registered dataset reaches R2 `ESTABLISHED`
  (a qualified quantitative retrospective instance).
- `COMPLETE_FAIL_CLOSED_ONLY_AUDIT`: every registered dataset is audited and reported with a
  documented terminal outcome (`ESTABLISHED` / `NOT_APPLICABLE` /
  `NOT_COMPARABLE_BY_REGISTERED_OBSERVATION_MODEL` / `NOT_COMPARABLE_BY_REGISTERED_ACTION_SPACE` /
  `NOT_ESTABLISHED`), and no dataset is left un-audited.

This is gate-preserving: the mandatory §8.4 audit-and-report obligation is unchanged; only the
add-specific hard requirement is removed.

## 3. Dataset terminal roles (as amended)

| dataset | observation modality | terminal outcome |
|---|---|---|
| add | continuous SHAPE (no categorical channel) | `NOT_COMPARABLE_BY_REGISTERED_OBSERVATION_MODEL` (unless a separately registered continuous-channel theorem is created) |
| sam-iii | continuous DMS (no categorical channel) | `NOT_COMPARABLE_BY_REGISTERED_ACTION_SPACE` (§8.5 diagnostic) |
| rorc | no public official accession | `NOT_APPLICABLE` (retain as a qualified fail-closed misspecification case when admissible) |

## 4. Invariants preserved

- T2 theorem readiness is **independent** of add / SAM-III / RORC eligibility (§12.2).
- Retrospective evidence remains **mandatory to audit and report**; it is only **optional as a
  qualified quantitative instance**.
- `scientific_claim_authorized` remains `False` for every phase; no prospective / blinded /
  held-out / independent-validation claim is authorized (§1.3).
- No fabricated dependency unit, observation model, or independence proof is introduced to force
  a gate pass.
